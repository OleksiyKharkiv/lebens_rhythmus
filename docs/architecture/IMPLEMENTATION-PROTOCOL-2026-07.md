## Трек A — Backend: auth + шифрование (LR-ADR-002)

**Что делаем:**
1. Ревизия `SecurityConfig`/`AuthService`/`JwtUtils`/`CustomUserDetailsService`
   — убрать AI-IDE artefacts, один явный путь: логин проверяет пароль →
   минтит JWT (OAuth2 Resource Server проверяет на входе). Хеширование —
   только в `UserService` (см. `KNOWN_ISSUES.md`, не трогать эту границу).
2. Field-level шифрование чувствительных колонок (адрес, телефон,
   банковские реквизиты если появятся) — JPA `AttributeConverter`.
3. `JWT_SECRET` — из Helm `value:` в `secretKeyRef` (см.
   `ARCHITECTURE_OLD.md` §4.3) — инфра-часть этого трека.
4. Локальный прогон: `./gradlew compileJava`, `./gradlew test`
   (`PasswordEncoderTest` как регрессия, плюс новый тест на реальный
   `register()→authenticate()` — см. рекомендацию Ханта из Round 1).

**Не трогаем в этом треке:** роль "Преподаватель" (LR-ADR-004) — Волна 2,
отдельная задача.

## Трек B — БД: Flyway + пересоздание схемы (LR-ADR-003)

**Что делаем:**
1. Добавить Flyway в `build.gradle`, убрать `spring.jpa.hibernate.ddl-auto=update`.
2. Удалить `DatabaseFixConfig` (см. запрещённый паттерн в
   `CODING_PROTOCOL.md`) — заменить его смысл нормальной миграцией.
3. `V1__baseline.sql` — честный снимок текущей entity-модели как отправная
   точка, не "исправленная" версия — исправления (напр. NOT NULL правки
   из `DatabaseFixConfig`) идут отдельными `V2`, `V3` и т.д., с явным
   объяснением в комментарии миграции.
4. Тест локально: `./gradlew flywayInfo`/`flywayValidate`, при доступности
   Docker — реальный прогон против Postgres (Testcontainers уже
   подключены в `build.gradle`).

## Трек C — Frontend: снос и стройка с нуля (LR-ADR-001, 014, 015)

**Что делаем:**
1. Каркас нового проекта — SvelteKit (решено, см. ниже) в **`frontend-svelte/`**
   (отдельная директория, не `frontend/`!) — старый статический сайт в
   `frontend/` не трогаем до готовности замены.
2. Первые три страницы — Home, About, Login/Register (LR-ADR-010) —
   строго по координатам LR-ADR-014: элегантность, яркие живые цвета,
   мягкий округлый шрифт, почти без анимации (1/5), без видео на Home.
3. Home — три обязательных модуля по LR-ADR-015: фото/видео с занятия,
   кнопка «Записаться», список направлений. Ничего другого в первый
   экран не добавлять без нового решения.
4. Perf-бюджет (LR-ADR-008) проверять с самого начала, не постфактум.

**Не трогаем в этом треке:** личный кабинет, роль "Преподаватель",
оплата — Волна 2.
